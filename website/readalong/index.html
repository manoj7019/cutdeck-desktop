Readalong

A desktop PDF reader that reads PDFs aloud with a natural, neural voice and highlights each word and sentence exactly as it is spoken. Windows and Mac.

Download for Windows Download for Mac

One zip for both. The voice runs on your computer (Kokoro on ONNX). Older versions.

What it does

  • Reads the page aloudA natural neural voice, running on your computer. Nothing is uploaded.
  • Follows the wordsEach word and sentence is highlighted exactly as it is spoken.
  • Start where you clickClick a word to read from there. Left and right move one sentence. Space plays or pauses.
  • The bar at the bottomHighlight mode is word, sentence, both, or off. Speed and voice are there too.
  • Picks up the book againIt remembers where you stopped in each book.
  • Skips the furnitureRunning headers and page numbers are not read out.

Keys

  • SpacePlay or pause.
  • Left / RightPrevious or next sentence.
  • Ctrl + / Ctrl −Zoom.
  • Ctrl OOpen a PDF.

Opening it the first time

Windows and Mac only. The first run sets itself up (about 250 MB, a few minutes). The first time you press play, the voice downloads once (120 MB).

Windows

Unzip the folder somewhere permanent, for example Documents\Readalong. Double-click Readalong.bat.

Optional: double-click Create desktop shortcut.bat for a desktop icon. You can drag a PDF onto that icon to open it.

Mac

Double-click Readalong.command. If macOS blocks it, right-click it, choose Open, then Open again.
