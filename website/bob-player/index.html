Small on purpose

The whole program is a bar. These are the parts he actually uses.

Bar

Always a small floating bar

No window frame and no maximize button. It opens about 520 by 92 pixels, parked at the bottom-right of the screen. Drag the bar to move it. The playlist can fold out under it, and fold away again.

Memory

The list is still there tomorrow

Songs you add, the last track, the loop mode, and the volume are written to a file in AppData and read back the next time the app opens. The files themselves stay where they already are on disk.

Loop

Off, the list, or one song

The loop button cycles three ways. Off plays through and stops after the last song. Loop playlist wraps around. Repeat one starts the current song again when it ends.

The rest of the player

Everything else it does

Open a song

  • Drop music or video files onto the bar, or use the open button.
  • The dialog allows several files at once. A path already in the list is not added twice.
  • The first time the list goes from empty to something, that first file starts playing.

Playback

  • Previous, play or pause, and next. Previous and next wrap around the list.
  • Click the bar under the title to seek. It shows the position while a file is open.
  • The line under the title shows time, duration, and which song this is, like “2 of 4”.
  • Double-click a row in the playlist to play that file.
  • If Windows cannot open a file, the bar says “Can’t play this file”.

Volume

  • Roll the mouse wheel over the window. Each notch moves the volume by 5%.
  • The subtitle shows the percent for a moment, then goes back to the time.
  • A new install starts at 80%. After that, the saved volume comes back.

Playlist

  • A button folds the list open under the bar, and folds it away again.
  • The playing row is marked. Select a row and press Delete to remove it.
  • Deleting the song that is playing stops playback.
  • On the next launch, a saved path is skipped if the file is no longer there.

Pin

  • The pin keeps the bar on top of other windows.
  • Unpin puts it back in the normal stack. Closing the app clears the pin; it is not saved with the playlist.

Files it will open

  • Audio: mp3, m4a, m4b, aac, wav, wma, flac, alac, ogg, opus, oga, aiff, aif, ac3, amr.
  • Video containers, for the audio in them: mp4, mkv, mov, avi, webm, wmv, 3gp, mka. There is no picture. The bar only plays sound.
  • All files is in the dialog too. Playback goes through Windows’ own media stack, so a rare codec can still fail.

Install

First launch

Windows only. Download the exe and run it. There is no setup wizard.

Windows SmartScreen

The exe is not code-signed. SmartScreen says Windows protected your PC. Choose More info, then Run anyway.

It needs .NET Framework 4.8, which is already part of Windows 10 and 11. If Windows asks you to install it, do that, then open the exe again.

Where the playlist is saved

%AppData%\BobPlayer\playlist.txt — usually C:\Users\<you>\AppData\Roaming\BobPlayer\playlist.txt. It stores the song paths, the last track, the loop mode, and the volume. Deleting that file starts you over.
