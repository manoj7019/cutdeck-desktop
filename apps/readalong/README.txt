READALONG
Reads PDFs aloud with a natural neural voice and highlights each word and
sentence exactly as it is spoken.

WINDOWS
  1. Unzip this folder somewhere permanent (for example Documents\Readalong).
  2. Double-click Readalong.bat.
     The first run sets everything up (a few minutes, about 250 MB).
     The first time you press play, the voice downloads once (120 MB).
  3. Optional: double-click "Create desktop shortcut.bat" for a desktop icon.
     You can drag a PDF onto that icon to open it.

MAC
  Double-click Readalong.command. If macOS blocks it, right-click it,
  choose Open, then Open again.

USING IT
  Space ........ play / pause
  Left / Right . previous / next sentence
  Click a word . start reading from there
  Ctrl + / - ... zoom
  Ctrl O ....... open a PDF

  The bar at the bottom sets what is highlighted (word, sentence, both, off),
  the speed, and the voice. Readalong remembers where you stopped in each book.
  Running headers and page numbers are skipped when reading.

Your settings and the voice files are kept in %LOCALAPPDATA%\Readalong
(Windows) or ~/Library/Application Support/Readalong (Mac). If something goes
wrong, readalong.log in that folder has the details.
